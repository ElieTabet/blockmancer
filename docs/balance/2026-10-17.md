# Balance bot: 2026-10-17

`melos run balance-bot`, which runs `dart run tool/balance_bot.dart` in
`packages/blockmancer_engine` with its default of 2,000 runs. Seeds 1 to 2,000 for each build, on
`defaultConfig` (targets 250 / 500 / 900 / 1,400 / boss 2,000). The run took 31.5 s for all five
builds on an 11-core M3 Pro.

| build | round 1 | round 2 | round 3 | round 4 | round 5 | median total | boss win |
|---|---|---|---|---|---|---|---|
| none | 99% | 87% | 67% | 59% | 53% | 5823 | 53% |
| patience,twin | 99% | 89% | 80% | 77% | 74% | 6681 | 74% |
| combo,collector | 99% | 90% | 80% | 76% | 72% | 6335 | 72% |
| heavy,bigbox | 99% | 90% | 71% | 58% | 47% | 5356 | 47% |
| stonemason,quarry | 99% | 81% | 52% | 41% | 36% | 2560 | 36% |

"round N" is the share of runs that cleared round N; round 5 is the boss, so it equals the boss win
rate.

## What changed since v0

Every tunable number now lives in `RunConfig`: the round targets, pieces and stones, chips per
cleared cell, and each joker's numbers (`JokerTuning`). The bot plays whatever config it is handed,
and the tool hands it `defaultConfig`, so editing a value there changes this table with no other
edit.

The values themselves did not move, so this is the same config as
[v0](../balance-v0.md), and every number matches it. That is the check that the move changed no
rule: a seed plays the same run as before.

How the bot plays, and what the table says against the brief's aim, are unchanged; see v0.
